# ScalePods Stock (demonstration)

A working demonstration of ScalePods Stock: stock book, plates, summary, physical count, orders and dispatch, invoices and payments, mail and leads, Tally, documents, drafts, sheet view and the Digital Brain.

Everything in it is **made up**: the companies, people, plates, invoices, mails and documents. There is no hosted database, no AI service and no Google account behind it, so it needs no keys and no settings.

## What is real and what is pre-written

| Part | In this demonstration |
|---|---|
| Screens, filters, charts, Excel downloads | Real, working code |
| Data | Made-up, held in an embedded database (PGlite) that is loaded from `demo-db/snapshot.tgz` when the server starts |
| Digital Brain, AI mode, Stock check | Pre-written answers: a question is matched to a sample question type, the real lookups run on the made-up data, and the answer is written from a template (`src/lib/ask/canned.ts`). Ask "help" to see the sample questions |
| Mail helper (write, reply, polish, summarise) | Template based (`src/lib/mail/assist.ts`) |
| Mailbox | A built-in sample Gmail (`src/lib/mail/fakeGmail.ts`). Sending, drafts, star, archive and trash work, and last until the server restarts |
| Document reader, RTGS bank reader | Make a believable reading from the made-up records; the checking rules are the real ones |
| Uploaded files | Kept in memory until the server restarts |

## Run it

```bash
npm install
npm run dev -- -p 3100
```

Open http://localhost:3100 and sign in with any of the demo accounts (any password). The accounts are an owner, an administrator, an approver, an accounts person and a viewer; each sees what that role would see.

## Deploy (Vercel)

Import the repository in Vercel and deploy with the defaults. No environment variables are needed.

## Rebuild the made-up data

The data is generated by the scripts in `demo-db/seed` (the same numbers come out every time) and saved as `demo-db/snapshot.tgz`. The dates are counted back from the day the data was built, so rebuild it shortly before showing the demonstration:

```bash
npm run db:build
```

The sample documents (`public/demo-docs`) are made by `node scripts/make-sample-docs.mjs`.
